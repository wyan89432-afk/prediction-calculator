OCR Upload + 24 Rows Table + Search

Paste-ready single-file app for GitHub Pages. Upload a photo, OCR extracts 3-digit numbers, fills a 24-row table, and search supports your custom single-digit logic plus * wildcards.
Single digit: custom pair logic * wildcard: exact 3-digit pattern 24 fixed rows
Ready.
How it works
• OCR scans the uploaded image for 3-digit numbers.
• Results are placed into 24 rows and as many columns as needed.
• Typing 0 to 9 uses your pair matching logic.
• Typing * patterns like *12, 21*, 1*2 uses wildcard matching.
